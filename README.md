# vPilot-Multiple-PushToTalk (MPTT)
vPilot plugin that allows multiple keybindings for PTT functionality.

100% vibe coded. No guarantee.

# Installation
1. Download the ZIP files here [Releases](https://github.com/Godehardt2003/vPilot-Multiple-PushToTalk/releases/tag/v1.0)
2. Move the folder `MultiplePTT` and `MultiplePTT.dll` into your Plugins folder, usually `C:\Users\XXX\AppData\Local\vPilot\Plugins`.

# Configuration
1. Start vPilot.
2. Open your system tray list and click on the MPTT icon <img width="35" height="36" alt="image" src="https://github.com/user-attachments/assets/bb1f7850-068d-437f-9d87-8add2b75b561" />
3. MPTT needs to emulate a virtual key press to trigger the vPilot PTT. To assign this virtual key (F14), open vPilot settings -> Push-To-Talk (PTT) and click on `Set new PTT Key or Button`. While vPilot is scanning, click in MPTT on `Send virtual key (after 3s)`. This process needs to be done only once!
4. By clicking on `Add` (in MPTT) you're able to add individual (multiple) keys to trigger the PTT. <img width="451" height="439" alt="image" src="https://github.com/user-attachments/assets/025d6a7e-1c2f-418f-aa0c-b6852741a5a8" />

This configuration is saved automatically.
