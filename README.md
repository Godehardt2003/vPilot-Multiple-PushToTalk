# Installation
1. Download the ZIP files here [Releases](https://github.com/Godehardt2003/vPilot-Multiple-PushToTalk/releases)
2. Extract the ZIP with **WinRAR** or **7-Zip**, not with the built-in Windows extractor.
3. Move the folder `MultiplePTT` and `MultiplePTT.dll` into your Plugins folder, usually `C:\Users\XXX\AppData\Local\vPilot\Plugins`.

> **Plugin doesn't start at all?** Windows may have blocked the DLL. Right-click `MultiplePTT.dll` -> Properties -> tick **Unblock** (or "Allow") -> OK, then restart vPilot.

# Configuration
1. Start vPilot.
2. Open vPilot settings -> Push-To-Talk (PTT) and **remove the PTT key or button assigned there**. Your keys must be assigned only in MPTT, not in vPilot AND MPTT, otherwise they interfere with each other.
3. Open your system tray list and click on the MPTT icon <img width="35" height="36" alt="image" src="https://github.com/user-attachments/assets/bb1f7850-068d-437f-9d87-8add2b75b561" />
4. By clicking on `Add` (in MPTT) you're able to add individual (multiple) keys to trigger the PTT. <img width="451" height="439" alt="image" src="https://github.com/user-attachments/assets/025d6a7e-1c2f-418f-aa0c-b6852741a5a8" />

This configuration is saved automatically.
